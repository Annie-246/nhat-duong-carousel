# nhat-duong-carousel

Claude Code skill.

Dựng bộ ảnh carousel Facebook 1080x1080 cho page "Nhật Dương – Xóa mù AI" theo template cam/lưới trắng (heading Inter Bold nền cam #E1825A, ảnh minh họa viền đen bo góc, bullet Inter Regular, chữ ký avatar ở đáy). Nhận nội dung dán vào hoặc link bài, tự chia slide, tự tìm ẢNH THẬT đúng chủ đề (ảnh chụp web/app thật, ảnh từ nguồn chính thức) nếu user chưa gửi ảnh, render PNG và xuất vào thư mục output theo tên "yy.mm.dd - nội dung bài". Dùng khi user nói "làm carousel", "làm carrousel", "làm ảnh carousel bài này", "dựng slide FB", dán một bài viết/list tool rồi bảo làm ảnh, gửi link bài kèm yêu cầu làm carousel, hoặc yêu cầu sửa/render lại một bộ carousel Nhật Dương đã dựng.
